# Matematika 9. (B) – II. Geometria – sokszögek (offline tankönyv)

Az NKP-s tankönyv fejezetei letöltve, egy nézegetőbe rendezve – internet nélkül is olvasható.

- `index.html` – nyisd meg ezt: bal oldalt a fejezetek listája, fent előző/következő gomb
- `tartozekok/fejezetek/` – a letöltött fejezetek és a hozzájuk tartozó képek, szkriptek
- `install.sh` – telepítő Macre

## Telepítés Macre

Terminálba másold be és nyomj Entert:

```
curl -fsSL https://raw.githubusercontent.com/Kiskujab/mankanak-matek-nkp/main/install.sh | zsh && source ~/.zshrc
```

Ez az Asztalra létrehozza a `manka-matek` mappát, letölt mindent, és beállítja a `manka-matek` parancsot.
Ezután bármikor elég a Terminálba beírni: `manka-matek`
